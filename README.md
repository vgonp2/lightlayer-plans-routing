## 回程三网都走移动 CMIN2，对实际体验意味着什么

美国优化线路的去程：电信和联通直连美国圣何塞的自家节点，然后接 Cogent 到洛杉矶机房；移动直连洛杉矶节点进机房。回程反过来，三网全部强制走移动 CMIN2（AS58807）高端链路回国，电信和联通用户也不例外。

这条路由安排的好处是方向统一，晚高峰不容易被塞进绕路的中转节点。代价是整条回国链路都压在移动的 CMIN2 上，移动侧出问题，三家用户一起受影响。2024 年 5 月的一篇测评做晚高峰测试时，移动测试节点本身出了故障，那组晚高峰数据并不完整。

延迟方面，2024 年 6 月的测评用电信 300M 家宽连接洛杉矶优化线路，ping 稳定在 160–170ms，波动很小，国内多节点测试零丢包；30M 带宽的套餐用脚本测速能跑满，晚高峰 21:30 本地下载约 3.6 MB/s。

2026 年 7 月的一轮复测里有个值得注意的细节：用联通 9929 家宽连接时操作明显卡顿，排查后发现延迟高达 234ms、丢包率约 30%。9929 用户基数不大，实际影响有限，但说明这条线路在联通方向还有优化空间。如果你正好是联通 9929 用户，下单前值得先买月付验证一下。

## 五个买前就该知道的限制

**1. 开通后所有端口默认关闭。** 机器交付后需要进防火墙设置手动添加要开放的端口，否则除了面板以外什么都连不上。第一次用的人经常以为是机器坏了，其实只是没放行。

**2. 升级规则分两种，而且不能互通。** 不限流量的 VPS 只能升级带宽大小，限流量的 VPS 只能升级流量，不能升级带宽。买之前就得想清楚走哪条路：要跑大流量下载选不限流量款，否则流量用完只能加流量，带宽永远卡在 20M 或 30M。

**3. 香港 IP 不是原生 IP。** 解锁 Netflix、Disney+ 这类流媒体大概率受限。日本、英国、德国机房提供原生 IP，部分套餐还是双 ISP 住宅 IP，需要解锁能力的应该往这几个机房选。

**4. 没有公开的退款政策，也没有明确的 SLA 承诺。** 售后走工单，响应通常几个小时，没有 7×24 在线客服，沟通以英文为主。这种条件下，先买月付试一个月比直接上年付稳妥。

适合的几类人：个人博客和小型站点，1 核 1G 放个静态站或轻量 CMS 完全够；需要一台便宜机器跑脚本、做定时任务、当跳板；面向国内用户、对延迟敏感但又不想付大厂价格；需要多机房部署做测试。

## 常见问题

**支持支付宝吗？**
2024 年 5 月的资料显示当时只支持 PayPal，后续会加支付宝、信用卡等。2026 年的公开资料称已支持支付宝、PayPal、信用卡，部分资料还提到加密货币。这块变动较快，以结账页实际显示的支付方式为准。

**能装 Windows 吗？**
可以，要求至少 2G 内存。默认提供 Linux 系统，需要手动切换。

**配置能随时升级吗？**
弹性云服务器支持升级 CPU、内存、硬盘、带宽，但受前面那条规则限制：不限流量款只能升带宽，限流量款只能升流量。降级一般要联系客服，特价年付套餐通常不支持升降级。

**有退款保证吗？**
没有公开的退款政策。遇到问题可以提工单协商，但别把它当成可依赖的退款通道。

**香港机房能解锁 Netflix 吗？**
香港 IP 不是原生 IP，解锁大概率受限。需要原生 IP 的选日本、英国或德国机房。
